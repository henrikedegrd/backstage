The set of app options that createApp will provide defaults for if they are not passed in explicitly.

Type declaration

  • Optionalcomponents?: Partial<AppComponents>

    A set of components to override the default components with.

    The override is applied for each app component individually.

  • Optionalicons?: Partial<AppIcons> & { [key in string]: IconComponent }

    A set of icons to override the default icons with.

    The override is applied for each icon individually.

  • Optionalthemes?: (Partial<AppTheme> & Omit<AppTheme, "theme">)[]

    A set of themes that override all of the default app themes.

    If this option is provided none of the default themes will be used.
