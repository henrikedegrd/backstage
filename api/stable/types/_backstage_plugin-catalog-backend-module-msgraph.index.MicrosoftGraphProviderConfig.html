The configuration parameters for a single Microsoft Graph provider.

Type declaration

  • Optionalauthority?: string

    The auth authority used.

    E.g. "https://login.microsoftonline.com"

  • OptionalclientId?: string

    The OAuth client ID to use for authenticating requests. If specified, ClientSecret must also be specified

  • OptionalclientSecret?: string

    The OAuth client secret to use for authenticating requests. If specified, ClientId must also be specified

  • OptionalgroupExpand?: string

    The "expand" argument to apply to groups.

    E.g. "member".

  • OptionalgroupFilter?: string

    The filter to apply to extract groups.

    E.g. "securityEnabled eq false and mailEnabled eq true"

  • OptionalgroupIncludeSubGroups?: boolean

    Whether to ingest groups that are members of the found/filtered/searched groups. Default value is false.

  • OptionalgroupSearch?: string

    The search criteria to apply to extract groups.

    E.g. ""displayName:-team"" would only match groups which contain '-team'

  • OptionalgroupSelect?: string[]

    The fields to be fetched on query.

    E.g. ["id", "displayName", "description"]

  • id: string

    Identifier of the provider which will be used i.e. at the location key for ingested entities.

  • OptionalloadUserPhotos?: boolean

    Set to false to not load user photos. This can be useful for huge organizations.

  • OptionalqueryMode?: "basic" | "advanced"

    By default, the Microsoft Graph API only provides the basic feature set for querying. Certain features are limited to advanced query capabilities (see https://docs.microsoft.com/en-us/graph/aad-advanced-queries) and need to be enabled.

    Some features like $expand are not available for advanced queries, though.

  • Optionalschedule?: SchedulerServiceTaskScheduleDefinition

    Schedule configuration for refresh tasks.

  • target: string

    The prefix of the target that this matches on, e.g. "https://graph.microsoft.com/v1.0", with no trailing slash.

  • tenantId: string

    The tenant whose org data we are interested in.

  • OptionaluserExpand?: string

    The "expand" argument to apply to users.

    E.g. "manager".

  • OptionaluserFilter?: string

    The filter to apply to extract users.

    E.g. "accountEnabled eq true and userType eq 'member'"

  • OptionaluserGroupMemberFilter?: string

    The filter to apply to extract users by groups memberships.

    E.g. "displayName eq 'Backstage Users'"

  • OptionaluserGroupMemberSearch?: string

    The search criteria to apply to extract users by groups memberships.

    E.g. ""displayName:-team"" would only match groups which contain '-team'

  • OptionaluserSelect?: string[]

    The fields to be fetched on query.

    E.g. ["id", "displayName", "description"]
