A reference to a backend service. You can use these references to mark dependencies on services and having their implementations injected automatically.

    Marks whether the service is a multiton or not. Multiton services the opposite of singletons - they can be provided many times, and when depended on, you receive an array of all provided instances.

  • scope: TScope

    This determines the scope at which this service is available.

    Root scoped services are available to all other services but may only depend on other root scoped services.

    Plugin scoped services are only available to other plugin scoped services but may depend on all other services.
